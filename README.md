# Anki Deck Library

공개 Anki 덱 라이브러리의 정적 사이트 저장소입니다.

[사이트 열기](https://dlquffhqnxj.github.io/anki-deck-site/)

현재 제품 10개, 등록 릴리스 13개, 버전별 실제 화면 26장, 동작 미리보기 12개를 제공합니다. 과목 필터, 화면 확대, 설치·업데이트 안내와 독립 QA 상태를 확인할 수 있습니다.

## 게시와 수정

GitHub Pages는 `.github/workflows/pages.yml`에서 main 변경을 게시합니다. 사이트 파일은 저장소 루트에 있으며 상대 경로를 사용합니다.

사이트 데이터는 2026-10-02에 확인한 등록 정보의 스냅샷입니다. 새 덱이나 릴리스를 등록하면 제작 저장소에서 사이트 번들을 다시 생성·검증하고, 공개용 파일만 이 저장소에 반영합니다. 이 저장소는 덱 원본과 QA의 기준이 아닙니다.

## 다운로드와 검증 범위

현재 다운로드는 비공개 제작 저장소의 GitHub Release로 연결되며 접근 권한이 필요합니다. 공개 미리보기를 볼 수 있다는 이유로 전체 APKG·MASTER 다운로드가 공개되는 것은 아닙니다.

덱의 STATIC·IMPORT·UPDATE·DEVICE 상태는 각 등록 기록대로 구분하여 표시합니다. 사이트의 브라우저 검사는 실제 Anki 가져오기·학습 기록 보존·기기 검사를 대신하지 않습니다. 손상된 EPD MASTER PACKAGE ZIP은 다운로드를 보류합니다.

## 공개 파일 범위

공개 HTML·CSS·JavaScript·카탈로그 JSON·대표 카드 이미지·미리보기 지원 자산·Pages 워크플로만 포함합니다. 원본 PDF, APKG, MASTER·XLSX, COLPKG, ZIP, 자격 증명, 내부 작업 인계와 검수 문서를 포함하지 않습니다. 기존 미리보기의 출처·표본 정보는 provenance.json에 유지합니다.

## 제삼자 라이선스 안내

`THIRD_PARTY_LICENSES.txt`는 포함된 KaTeX 수식 라이브러리에 대한 라이선스 안내입니다. 덱 콘텐츠를 포함한 나머지 프로젝트 자료에는 별도의 공개 라이선스를 부여하지 않습니다. 사용자 제공 자료·출판물·시험문항·외부 프로젝트는 각 원저작권과 이용 조건을 따릅니다.
