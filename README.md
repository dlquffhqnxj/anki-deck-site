# Anki Deck Library

[공개 덱 라이브러리](https://dlquffhqnxj.github.io/anki-deck-site/)

2026-11-19 기준 덱 10개, 제작 표본 2개, 공통 제작 플랫폼 1개와 이전 릴리스를 포함해 24건을 제공합니다. 대표 카드 화면 48장과 실제 카드 동작 미리보기 16개를 볼 수 있습니다. 별도 학습 예시 7개에서는 브라우저에서 정답과 해설을 확인할 수 있습니다.

과목·JLPT 급수·학습 목적과 검색어로 덱을 찾을 수 있습니다. 한자혁명 통합판은 덱 상세에서 기존 설치 버전을 고르고 3문항 체험을 시작할 수 있습니다. 체험의 혼동 이유는 사용자의 브라우저에 저장됩니다.

기존 버전의 대표 화면과 미리보기도 릴리스 기록에서 열 수 있습니다. 원본 HTML, APKG, MASTER, ZIP 같은 배포 파일은 [제작 저장소의 GitHub 릴리스](https://github.com/dlquffhqnxj/anki-deck-project/releases)에 있는 자산으로 연결됩니다. 파일을 받으려면 해당 저장소 접근 권한이 필요합니다.

덱 상세는 STATIC·IMPORT·UPDATE·DEVICE의 검사 범위를 릴리스 기록에 따라 표시합니다. EPD MASTER PACKAGE ZIP의 손상 기록에 따라 해당 ZIP의 다운로드는 보류합니다. 검증 기록이 있는 단독 APKG는 상세에서 받을 수 있습니다.

## 게시와 수정

GitHub Pages는 `.github/workflows/pages.yml`에서 main 변경을 게시합니다. 사이트 파일은 저장소 루트에 있으며 상대 경로를 사용합니다.

릴리스 목록과 자산은 제작 저장소의 공개 게시 상태와 대조한 스냅샷입니다. 등록 기준 커밋은 `51098886cacce8b0050c70d707092c3366974d96`입니다. 릴리스가 바뀌면 `data/library.json`과 브라우저용 `assets/library-data.js`를 함께 갱신합니다. Pages는 게시 전에 `python3 scripts/check_catalog.py`로 두 파일의 일치와 상세·미리보기·다운로드 경로를 검사합니다. 비공개 제작 저장소의 Check release library and previews 워크플로는 게시된 카탈로그를 실제 GitHub 릴리스와 대조합니다.

공개 저장소에는 HTML, CSS, JavaScript, 카탈로그와 대표 이미지를 둡니다. 기존 미리보기의 출처와 표본을 해당 경로의 `provenance.json`에서 확인할 수 있습니다.
