# 독립 웹 덱 제작기 변경 이력

[제작기 열기](https://dlquffhqnxj.github.io/anki-deck-site/deck-maker/)

## v0.7.0 · 2026-11-26

- **확신도 복습** — 객관식 정답 확인 후 ‘찍어서 맞혔어요’를 선택하면 확신도 복습에 담는다. 다시 맞혀도 아직 헷갈리는 문제는 목록에 남는다.
- **반복해서 헷갈린 보기** — 선택한 오답과 정답의 텍스트 조합을 덱별로 집계한다. 같은 조합을 두 번 이상 틀리면 실제 문항과 작성된 풀이 근거를 함께 볼 수 있다. v0.7.0에서 푼 답부터 집계한다.
- **7일 변형 문제 짝짓기** — 내 덱에서 원문항과 변형 문항을 검색하고 지문·질문·보기·정답을 비교한다. 원문항의 NoteID로 연결을 저장해 같은 개념 안에서도 지정한 변형 문항이 열린다. 설정은 누적 원본과 전체 백업에 포함된다.
- **디자인** — 제작 화면에서 누적 노트 수, 생성 카드 수, 최근 덱 버전을 구분하고 현재 단계의 작업을 강조한다. 모바일은 선택한 덱을 먼저 표시한다. 학습 카드는 채점 결과 근처에서 확신도를 바로 기록한다.

### 확인한 범위

Chromium에서 확신도 재도전, 자리를 바꾼 보기의 혼동 집계, 두 원문항에 각각 지정한 변형 지문, 390px 화면의 덱 전환과 백업 복원을 확인했다. 날짜를 조정해 6일째 대기, 7일째 재시험, 다시 틀렸을 때 14일째 재시험을 확인했다. Anki 26.9.4 엔진에서 v0.6.0의 195노트 덱을 업데이트해 카드 ID, 복습 이력과 예정일이 유지되는지 검증했다. iPhone·iPad 앱과 AnkiWeb 실사용 검증은 남아 있다.

## v0.6.0 · 2026-11-26

- **내 덱과 누적 제작** — 덱별로 원본·초안·카드 설정·제작 이력을 보관한다. 직접 작성하거나 표와 파일을 가져오면 신규·수정 후보·동일·충돌·급수 제외를 구분한다. 수정을 선택하면 같은 NoteID로 내용을 갱신한다. 이전 자료를 매번 합칠 필요 없이 누적 원본에서 APKG를 만든다.
- **버전과 복원** — 덱 전체 백업 ZIP에 원본, 작성 중인 내용, 설정, 이전 제작본을 담는다. 복원 시 파일 해시를 점검하고 과거 제작본을 다시 열 수 있다. 기존 브라우저의 v0.5.0 제작 이력은 같은 주소에서 내 덱에 연결된다.
- **오답 복습과 카드 설계** — 선택한 오답, 정답, 작성자가 입력한 풀이 근거와 보기 해설을 함께 본다. 학습자가 이유를 표시하고 최대 3문항씩 재도전한다. 회상·쓰기형은 정답 확인 후 스스로 판정한다. 내 덱의 학습 설계 점검에서 오답 비교 설명과 회상 근거가 비어 있는 노트를 바로 열 수 있다.

제작기 버전은 화면과 제작 기록에 표시한다. 덱 버전은 덱별로 관리한다. 학습 중 카드에서 남긴 오답 이유와 복습 미션은 학습 기기에 저장한다.

### 확인한 범위

Chromium에서 누적 제작, 덱별 초안 분리, 별도 브라우저 환경으로의 전체 백업 복원, 선택형 오답 재도전을 확인했다. Anki 26.9.4 엔진에서 기존 100노트에 신규 95노트와 수정 3노트를 반영했고, 학습한 카드의 복습 이력과 예정일이 유지됐다. iPhone·iPad와 AnkiWeb에서의 실사용 검증은 남아 있다.

### v0.7.0 학습 기능 후보

1. **확신도 복습** — 맞혔지만 찍은 문제를 표시해 별도로 다시 푼다.
2. **보기별 혼동 분석** — 같은 오답 보기와 정답을 반복해서 혼동한 조합을 모아 비교한다.
3. **7일 변형 문제 짝짓기** — 제작 화면에서 원문항과 다른 지문의 재시험 문항을 연결하고 두 문제를 함께 미리 본다.

## v0.5.0 · 2026-11-24

Kanji LAB v1.9.2형과 한자혁명 v1.10.0형을 제작 모델에 추가했다. 선택한 모델에 따라 작성 필드와 앞·뒷면, 학습 설정, 내 기록 구성이 달라진다.
