# 독립 웹 덱 제작기

같은 주소에서 노트를 모으고, 수정한 노트와 새 노트를 확인한 뒤 누적 APKG를 만듭니다. 첫 화면에서 **혼동 표현 10쌍 열기**를 누르면 20개의 일본어 예문으로 만든 10장을 직접 편집하거나 Anki용으로 제작할 수 있습니다. [제작기 열기](https://dlquffhqnxj.github.io/anki-deck-site/deck-maker/) · [10장 바로 풀기](https://dlquffhqnxj.github.io/anki-deck-site/deck-maker/contrast/) · [버전 이력](CHANGELOG.md)

## 내 덱에서 작성하고 받기

**새 덱 만들기**에서 카드 구성을 골라 노트 한 건이 몇 장의 카드가 되는지 확인합니다. **오늘 분량 추가**에서 내용을 입력하고 앞면·뒷면과 카드 유형을 전환합니다. 노트를 비교하면 저장 후의 수량을 볼 수 있습니다. 기존 노트의 해설만 바꾼 경우 수정 후보를 선택합니다. **선택한 분량 누적 저장 → 제작·APKG 받기**를 누르면 같은 화면에서 다운로드합니다. 다음에 방문하면 저장한 덱의 작성 초안을 이어 쓸 수 있습니다.

## 오답을 다음 덱에 반영하기

1. 학습 카드에서 객관식 보기를 고릅니다. 같은 오답·정답 조합이 두 번 쌓이면 **오답 복습 → 반복해서 헷갈린 보기**에서 조합을 펼치고 **이 오답으로 문제 만들기**를 누릅니다.
2. 나온 코드를 복사합니다. 제작기에서 같은 덱을 열고 **학습 기록 가져오기 · 버전별 검수 → 이 덱에 기록 반영**을 누릅니다. 다른 기기에서는 JSON 파일로도 옮길 수 있습니다.
3. 준비한 표현 쌍은 예문 두 개가 채워집니다. 직접 추가할 때는 각 표현이 한 번씩 정답이 되게 문장을 쓰고, 문장 안에서 결정 단서와 비교할 단서를 지정합니다. **검토한 미션 누적**을 눌러야 원본에 반영됩니다. 같은 표현 쌍은 기존 미션의 원문항 연결을 늘립니다.
4. **누적 덱 제작**을 누르고 새 APKG를 받습니다. 개별 미션은 두 표현과 두 결정 단서를 모두 맞혀야 완료됩니다. 표본의 급수는 덱 안에서 정리하기 위한 제작 분류입니다.

## 보기를 보기 전 회상하기

읽기 또는 동사 활용이 지정된 노트와 단어 읽기 카드에서 먼저 답을 써 봅니다. 가나 읽기는 폭과 히라가나·가타카나 차이를 허용합니다. 보기를 열고 맞힌 항목은 **보기 도움 …문제 다시 쓰기**에서 한 번에 세 개까지 다시 풉니다. 보기 후보가 없는 단일 읽기 노트에서는 답을 확인할 수 있습니다.

## 이전 버전과 비교하기

두 덱 버전에서 푼 학습 기록을 각각 가져오면 같은 노트에서 같은 보기를 잘못 고른 횟수와 전체 채점 응답 수를 나란히 볼 수 있습니다. 혼동 미션은 두 문장을 각각 한 응답으로 셉니다. 직접 정답과 보기 후 정답은 별도 집계합니다. 기기별로 마지막 집계를 보관하므로 같은 파일을 두 번 가져와도 횟수는 늘지 않습니다. 보관한 제작본이 모두 있으면 질문·보기·풀이 중 바뀐 항목을 표시합니다. 적은 횟수는 문장을 다시 읽어 볼 단서로 활용하세요.

노트·초안·제작본은 제작에 사용한 브라우저에, 학습 중 남긴 기록은 해당 기기의 학습 환경에 저장됩니다. 기기 간 제작 작업은 **전체 백업 ZIP**으로, 학습 집계는 **코드 또는 JSON**으로 옮깁니다. 구버전에서 수집하지 않은 버전별 응답 수는 v0.8.0으로 제작한 카드에서 학습한 뒤부터 표시됩니다.
