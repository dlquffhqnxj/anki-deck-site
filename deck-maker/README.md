# 독립 웹 덱 제작기

같은 주소에서 노트를 모으고, 수정한 노트와 새 노트를 확인한 뒤 누적 APKG를 만듭니다. 첫 화면에서 **혼동 표현 10쌍 열기**를 누르면 20개의 일본어 예문으로 만든 10장을 직접 편집하거나 Anki용으로 제작할 수 있습니다. [제작기 열기](https://dlquffhqnxj.github.io/anki-deck-site/deck-maker/) · [10장 바로 풀기](https://dlquffhqnxj.github.io/anki-deck-site/deck-maker/contrast/) · [버전 이력](CHANGELOG.md)

## RULE-06 v1.3.0 적용 기록

새 후보는 `RUN.json`과 `manifest.json`에 운영 기준 날짜와 SHA-256, 제작 모델, 카드 UI와 템플릿 해시, 기능별 포함 여부·기본값, 파트별 수량 및 검수 결과를 기록합니다. 검증 탭에서 실제 앱·기기 검사 결과를 입력하면 두 기록과 `QA.json`이 함께 갱신됩니다. 이전 후보는 제작 당시의 기록과 파일로 다시 열 수 있습니다.

후보 생성은 SQLite와 필드, 식별자, 파트별 수량 및 APKG·HTML 표본 앞뒷면을 자동 검사합니다. Anki 앱 가져오기·업데이트, 실기기, AnkiWeb 및 배포 파일 확인에는 해당 환경에서 수행한 검사 근거를 입력합니다. 미리보기의 파트·변경 필터와 NoteID·CardID로 확인할 카드를 찾을 수 있습니다.

## Anki 사용법 미리보기

한자 노트의 입력값을 바꿔 앞·뒷면 6개를 비교하고, 실제로 가져올 APKG를 내려받을 수 있습니다. 단어 카드에서는 직접 입력과 보기 후 다시 쓰기를, 객관식 카드에서는 확신도와 반복 오답을 연습합니다. 두 원문항에서 받은 코드를 반영하고 검토하면 3장 누적 덱을 받습니다. 같은 원본을 제작기에서 열 수 있는 백업 ZIP도 제공합니다. [사용법 열기](https://dlquffhqnxj.github.io/anki-deck-site/deck-maker/?guide=anki)

오래된 **JLPT N5 제작 표본**은 새로고침한 뒤 기존 덱을 그대로 엽니다. 카드에 새 학습 기능을 넣을 때는 **누적 덱 제작** 후 **내 덱 → APKG 받기**로 받아 같은 Anki 컬렉션에 가져옵니다.

## 내 덱에서 작성하고 받기

**새 덱 만들기**에서 카드 구성을 골라 노트 한 건이 몇 장의 카드가 되는지 확인합니다. **오늘 분량 추가**에서 내용을 입력하고 앞면·뒷면과 카드 유형을 전환합니다. 노트를 비교하면 저장 후의 수량을 볼 수 있습니다. 기존 노트의 해설만 바꾼 경우 수정 후보를 선택합니다. **선택한 분량 누적 저장 → 제작·APKG 받기**를 누르면 같은 화면에서 다운로드합니다. 다음에 방문하면 저장한 덱의 작성 초안을 이어 쓸 수 있습니다.

## 내 덱에서 공부하고 복습하기

1. 노트를 누적 저장한 뒤 **공부 시작**을 누릅니다. APKG를 만들기 전에도 풀 수 있습니다. 읽기·활용은 직접 입력하거나 보기를 열어 답하고, 객관식 정답은 확신도를 고릅니다.
2. 오답, 찍어서 맞힌 답, 보기를 열고 맞힌 답이 해당 카드의 개인 복습 목록에 쌓입니다. 같은 브라우저에서 덱을 다시 열고 **복습할 카드**를 누르면 오래된 카드부터 최대 세 장을 풉니다. 결과에서 이번 묶음의 회복 수와 직접 떠올려 맞힌 수를 확인합니다. 다른 카드 유형과 다른 덱은 각각 따로 집계합니다.
3. 같은 객관식 오답 조합이 두 번 쌓이면 **반복해서 헷갈린 보기 → 이 오답으로 문제 만들기**를 누릅니다. 두 표현이 한 번씩 정답이 되는 예문과 결정 단서를 검토하고 **검토한 미션 누적**을 누릅니다. 기존 미션이 있으면 원문항을 연결합니다. **제작·APKG 받기**로 누적한 덱을 내려받습니다.

Anki 앱이나 별도 학습 파일에서 푼 결과는 카드의 **제작기에 학습 기록 보내기**에서 코드 또는 JSON을 받아, 제작기의 **학습 기록 가져오기 · 버전별 검수**에서 반영합니다.

## 보기를 보기 전 회상하기

읽기 또는 동사 활용이 지정된 노트와 단어 읽기 카드에서 먼저 답을 써 봅니다. 가나 읽기는 폭과 히라가나·가타카나 차이를 허용합니다. 보기를 열고 맞힌 항목은 **보기 도움 …문제 다시 쓰기**에서 한 번에 세 개까지 다시 풉니다. 보기 후보가 없는 단일 읽기 노트에서는 답을 확인할 수 있습니다.

## 이전 버전과 비교하기

제작한 두 덱 버전을 같은 브라우저에서 공부하거나 다른 기기의 학습 집계를 가져오면 같은 노트에서 같은 보기를 잘못 고른 횟수와 전체 채점 응답 수를 나란히 볼 수 있습니다. 혼동 미션은 두 문장을 각각 한 응답으로 셉니다. 직접 정답과 보기 후 정답은 별도 집계합니다. 기기별로 마지막 집계를 보관하므로 같은 파일을 두 번 가져와도 횟수는 늘지 않습니다. 보관한 제작본이 모두 있으면 질문·보기·풀이 중 바뀐 항목을 표시합니다. 적은 횟수는 문장을 다시 읽어 볼 단서로 활용하세요.

노트·초안·제작본은 제작에 사용한 브라우저에, 학습 중 남긴 기록은 해당 기기의 학습 환경에 저장됩니다. **전체 백업 ZIP**에는 원본과 제작본, 반영한 버전별 학습 집계가 들어갑니다. 개인 복습 목록과 이어 풀던 위치는 이 브라우저에 저장됩니다. 구버전에서 수집하지 않은 버전별 응답 수는 v0.8.0으로 제작한 카드에서 학습한 뒤부터 표시됩니다.
